# 💰 Personal Expense Tracker

A web-based Personal Expense Tracker developed as a BCA project to help users record, manage, and analyze their daily expenses.

## 📌 Project Description

The Personal Expense Tracker allows users to maintain their expenses in an organized way. Users can add, edit, and delete expenses and analyze their spending using category-wise and monthly summaries.

The application also identifies the highest expense and provides spending insights based on the user's actual expense data.

## ✨ Features

### 1. Add Expense
- Add a new expense with:
  - Expense name
  - Amount
  - Category
  - Date
  - Description

### 2. Edit Expense
- Update the details of an existing expense.
- Edit the amount, category, date, or other information.

### 3. Delete Expense
- Delete unwanted expenses.
- Confirmation is provided before deletion.

### 4. Category-wise Summary
- View total spending for each category.
- Categories include:
  - Food
  - Travel
  - Shopping
  - Bills
  - Education
  - Health
  - Entertainment
  - Other

### 5. Monthly Summary
- View total spending for a selected month.
- Display:
  - Total spending
  - Number of transactions
  - Average expense

### 6. Highest Expense
- Automatically identify the highest single expense.
- Display the expense name, amount, category, and date.

### 7. Spending Insights
The application generates insights from the recorded expenses, such as:
- Highest spending category
- Total monthly spending
- Average expense
- Highest individual expense
- Number of transactions

## 📊 Dashboard

The dashboard provides:

- All-time spending
- Current month's spending
- Highest expense
- Total number of transactions
- Spending over time
- Category-wise spending
- Monthly statistics
- Spending insights
- Recent transactions

## 🔍 Search and Filter

Users can:
- Search expenses by name
- Filter expenses by category
- Filter expenses by date/month
- Sort expenses based on date or amount
